# AI Internship Projects

This repository contains machine learning and neural network implementations developed during my industry training.

The main purpose of these projects was to understand the mathematical foundations of machine learning and neural networks by implementing the algorithms from scratch.

## Projects

### 1. Support Vector Machine From Scratch

A linear Support Vector Machine (SVM) implemented from scratch without using machine learning libraries.

The implementation includes:

- Hard and soft margin options
- Hinge loss
- L2 regularization
- Gradient-based optimization
- Decision boundary
- Margin visualization

Folder: `SVM_From_Scratch`

---

### 2. Gaussian Distribution Classification From Scratch

A Gaussian Distribution based classification algorithm implemented from scratch using its mathematical foundations.

The implementation includes:

- Class-based statistical calculations
- Mean and variance calculation
- Gaussian probability density
- Probability-based classification

Folder: `Gaussian_Classification`

---

### 3. Artificial Neural Network From Scratch

A fully connected feedforward Artificial Neural Network implemented using Python and NumPy without TensorFlow, Keras, or PyTorch.

Architecture:

- 2 input neurons
- 4 hidden neurons
- 1 output neuron
- ReLU hidden activation
- Sigmoid output activation

The implementation includes:

- Weight and bias initialization
- Forward propagation
- ReLU activation
- Sigmoid activation
- Binary Cross-Entropy loss
- Backpropagation
- Gradient descent
- Training and prediction

Folder: `ANN_From_Scratch`
